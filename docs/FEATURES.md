# Feature-completeness matrix

Implemented means working code exists; it does **not** certify every requirement in a phase. Release acceptance remains open while the original 49-row fixture, physical iPhone checks, and the remaining checklist are outstanding.

| Area                   | Implemented behavior and evidence                                                                                                                                                                                                           | Remaining / limits                                                                                                                     |
| ---------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| Foundation             | React strict TS, Vite, Tailwind, Dexie v1→v3, Zustand, hash routing, installable PWA, precache, update prompt, local status                                                                                                                 | Public Pages/offline origin verified; physical standalone test pending                                                                 |
| Persistent sessions    | Transactional start/finish, absolute elapsed time, pause/resume, edit start/end, discard, category conflicts, simultaneous categories/children, stable completion ID                                                                        | Physical OS suspension/reboot and clock-change scenarios need iPhone checks                                                            |
| Profiles               | Multiple local children, DOB, accurate calendar age, sex/reference, gestation and photo; mobile/desktop selectors                                                                                                                           | Global units rather than independent per-child unit overrides                                                                          |
| Tracking               | Detailed forms and historical CRUD/notes across all 14 categories; category repository CRUD and browser native-form coverage                                                                                                                | Broader field-permutation browser coverage remains                                                                                     |
| Nursing                | Sequential segments, per-side live controls including simultaneous sides, pause/resume, manual totals, historical segment editor, imported totals without invented sequence                                                                 | Additional simultaneous-side UI tests desirable                                                                                        |
| Diapers                | Pee/poop/mixed/dry, independent amounts, color, consistency, rash/leak unknown states, tags, notes/photo; conditional-field tests and correct mixed counts                                                                                  | Physical camera/file integration pending                                                                                               |
| Bottle / pumping       | Consumed vs offered, milk type/mixed breakdown, canonical integer volumes, separate pumping output/sides, unknown imported duration                                                                                                         | Additional mixed-bottle permutations and display-unit customization desirable                                                          |
| Solids                 | Multiple/custom foods, meal and individual food details, quantities, texture, reaction, allergens, observed reactions, photos, exposure/favorite/retry report                                                                               | More dedicated food-library browsing could improve convenience                                                                         |
| Medicine / temperature | Administration instructions and history, user-configured reminders; canonical °C and method-specific recorded observations                                                                                                                  | No dosing advice or automatic health diagnosis by design                                                                               |
| Other modules          | Growth, potty, activities, milestones, contractions, custom typed fields all persist and appear in History/Reports                                                                                                                          | No reference milestone age deadlines are invented                                                                                      |
| CSV migration          | Worker CSV parser, per-type registry, IANA timezone confirmation, DST review, warnings/inference review, raw provenance, SHA-256 fingerprints, transactional import and audit                                                               | Original 49-row acceptance fixture missing; dedicated corrected-record reconciliation / row time correction remain                     |
| History                | Date picker, calendar month grid, daily timeline, all-date search, category filter, notes/details, edit/delete with undo, duplicate                                                                                                         | Bounded pagination instead of virtual scrolling                                                                                        |
| Analytics              | Central calendar clipping, interruption subtraction, interval union, nights/boundaries, rolling totals, consumed milk, mixed counts, output, range buckets                                                                                  | Long real-device dataset benchmarks still needed                                                                                       |
| Visuals                | Linked radial rings / actogram / daily timeline, selection without shifting range, 7/14/30+ days, ring pagination, live provisional arcs, feeding markers, zoom/pan/filter/day comparison                                                   | Wake-window ring overlay and side-by-side previous-week radial mode not yet provided                                                   |
| Growth                 | Eight real WHO/CDC LMS tables bundled with hashes/sources, z/percentiles, 5/50/95 reference curves, measurements and velocity, optional corrected age                                                                                       | Birth–24 months/45–110cm only; no standing-height percentile or extreme-tail percentile; broader independent reference cases desirable |
| Prediction             | Deterministic 7/14/30-day robust recency blend, window sequence, age/corrected age, short/long naps, recorded nights, bedtime, confidence/explanations, overrides/disable                                                                   | Not clinically validated; broader longitudinal scenario coverage pending                                                               |
| Schedules              | Feasibility checks, 0–5 nap UI, editable times, save multiple options, remaining-day recalculation, planned/actual comparison                                                                                                               | Direct time inputs rather than drag gestures                                                                                           |
| Sleep plans            | Local intake, age-sensitive responsive rules, preferences, goals, steps/checks, notes, versions/revisions, optional saved schedule snapshot, before/during recorded comparison                                                              | More rule/preference permutation tests needed                                                                                          |
| Insights               | Actual sleep timing/totals, feeding shifts, diapers, pumping time-of-day, solids favorites, growth and development observations, support/date/confidence/dismiss                                                                            | Descriptive only; incomplete tracking limits conclusions                                                                               |
| Reports                | Range presets/custom, interactive sleep/milk/output/diaper/growth/temperature charts, wake windows, clock wraparound, reconstructed-vs-observed estimates, solids/activity/potty/development/medicine/custom/contraction reports, CSV/print | Not every chart mode is a distinct export dataset yet                                                                                  |
| Convenience            | Deterministic offline text→review drafts, multi-entry review, persistent reminders and overdue dashboard, all custom field types                                                                                                            | Optional voice/OCR interpretation not implemented                                                                                      |
| Data safeguards        | SHA-256 JSON/media ZIP snapshots, isolated test restore, staged replacement and conflict merge, retained safety database, three-generation verified external rotation, encryption, truthful backup states and reminders                     | Further storage-pressure and malformed-file fuzzing on-device pending                                                                  |
| UX                     | Warm responsive identity, themes, bottom safe-area nav, large common actions, reduced motion, native labels, modal keyboard management, tile visibility/order, panel visibility/order, compact mode                                         | Formal accessibility certification and physical one-handed usability review pending                                                    |
| Release                | Build/test scripts, Pages workflow/subpath setting, source/reference docs, manual checklist                                                                                                                                                 | Pages deployed and origin verified; full hardware acceptance remains pending                                                           |
| Required 49-row demo   | Eight synthetic-date rows regression-tested online/offline with exact values, linked views, timers, backup/restore, duplicate protection                                                                                                    | **BLOCKED: original 49 rows were not provided**                                                                                        |
